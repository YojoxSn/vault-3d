# Developer notes

The application lives in this folder. Everything else in the repository is documentation.

```bash
npm install
npm run dev            # http://localhost:5173 (landing page: demo, or drop a vault folder)
npm test               # parser, gesture and orb-layout tests (no camera needed)
npm run typecheck
npm run build          # production build in dist/
npm run build:graph -- "/path/to/vault"   # generate public/graph.json only
```

Load your vault automatically: copy `.env.example` to `.env` and set `VAULT_PATH`. The vault is read-only. `.env`, `public/graph.json` and `public/content.json` contain your notes and are git-ignored.

| Folder | What |
|---|---|
| `src/parser/` | Markdown to graph (links, tags, ghosts). Pure functions, shared by the browser and the CLI |
| `src/scene/` | Three.js: instanced spheres, glowing links, particles, bloom, hologram pass, orb layout, layout worker |
| `src/hands/` | MediaPipe wrapper, One Euro filter, pure gesture recognition, gesture state machine |
| `src/ui/` | Panels, search, filters, landing page, floating camera window |
| `scripts/` | Graph builder, demo vault generator |
| `tests/` | Vitest. Gestures are tested with simulated landmarks |
| `example-vault/`, `public/demo/` | The fictional demo vault (generated by `npm run build:demo`) |

Rules of thumb: gesture logic stays **pure** (no DOM, no MediaPipe) so it can be unit-tested, and anything touching the user's notes stays **read-only and local**.

Tuning hand tracking: `CFG` in `src/hands/engine.ts` and the thresholds in `src/hands/gestures.ts`. If "both palms" fires on the backs of your hands, set `PALM_FLIP = true`.

The site is deployed by `.github/workflows/pages.yml` (Settings → Pages → Source: GitHub Actions).
